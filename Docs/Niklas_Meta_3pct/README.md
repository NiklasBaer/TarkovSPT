# Niklas_Meta_3pct

APBS-Preset mit progressiver Meta-Orientierung und ca. 3 % Shotgun-Gewichtung pro PMC-Nahbereichs-Waffenpool.

## Installation
1. Nur die 35 JSON-Dateien aus `Presets/Niklas_Meta_3pct/` nach `SPT/user/mods/acidphantasm-progressivebotsystem/Presets/Niklas_Meta_3pct/` kopieren.
2. Die Werte aus `APBS_config_patch.json` in die bestehende APBS-`config.json` übernehmen. Nicht die ganze Config ersetzen.
3. Server neu starten.

## Meta-Ausrichtung
Ab Tier 4 werden leistungsfähige Waffen stärker gewichtet, darunter HK416A5, MDR 7.62, Mk47 Mutant, AK-12 und RD-704. A-Tier-Optionen wie M4A1, SA-58, SR-25, TX-15, AUG A3, AK-105 und AS VAL werden moderat bevorzugt. Höhere Tiers erhalten bessere Munition und höhere Chancen auf sinnvolle Kernaufsätze.

## Shotguns
Shotguns werden in jedem PMC-Nahbereichspool separat auf 3 % der gesamten Waffengewichtung gesetzt. Long-Range-Pools bleiben unberührt.

## Technische Grenze
APBS zieht Aufsätze zufällig aus kompatiblen Tier-Modlisten. Das Preset verbessert daher die Wahrscheinlichkeit für vollständige, starke und meta-orientierte Builds, garantiert aber keine identischen 1:1-Community-Blueprints. Dafür wäre ein zusätzlicher Generator für feste waffenspezifische Rezepte nötig.
